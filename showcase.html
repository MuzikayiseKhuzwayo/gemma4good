Deterministic Edge Architecture

Built from the ground up for zero-crash execution, strict least privilege, and air-gapped sovereignty.

⚡

Speculative Dual-Kernel

Sub-50ms deterministic regex and pattern routing via GemmaMicroKernel, with seamless speculative escalation to GemmaDeepKernel for multi-step reasoning.

🛡️

Capability Security

Least-privilege security model with automated unified diff generation. Host file modifications and network requests require explicit operator authorization.

🧠

3-Tier Memory Paging

Context budgeting with L1 Active Working Memory, L2 Episodic Compressed Memory, and L3 Persistent SQLite Vector Storage with on-demand page fault resolution.

🌐

Sovereign P2P Mesh

Air-gapped peer discovery and task gossip over local UDP broadcasts (port 5005). Operates without cloud backends or external telemetry.

💻

Isolated Code Sandbox

Execute untrusted or dynamic Python scripts and WebAssembly modules with timeout protection, stdout/stderr capture, and isolated globals.

📊

Associative Knowledge Graph

Embedded SQLite entity-relationship triplets extracted from conversation traces, answering associative queries like "Who did I talk to about Physics?"
